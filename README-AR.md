# نظام إدارة عيادة الطبيب محمد بسام حايك v0.7.1

## الجديد
- تعديل هوية العبارة الجانبية إلى اسم نظام العيادة الكامل.
- قائمة المستخدم في أعلى يسار الشاشة بأيقونة بسيطة.
- تعديل الاسم الظاهر واسم المستخدم وكلمة المرور.
- عرض الوصفات المحفوظة كاملة من ملف المريض وإعادة طباعتها.
- استعادة نسخة احتياطية سابقة من واجهة التقارير.
- إنشاء نسخة أمان pre-restore تلقائياً قبل كل استعادة.
- تسجيل الخروج تلقائياً بعد الاستعادة لإعادة تحميل البيانات والصلاحيات بأمان.
- استمرار التقارير والمخططات والتحليل الذكي المحلي من v0.7.0.

## التشغيل
1. ثبّت Node.js 22.5 أو أحدث.
2. فك الضغط في مجلد ثابت، مثل C:\\Hayek-Clinic-EMR.
3. شغّل تشغيل-الخادم.bat.
4. افتح http://localhost:8787.
5. بيانات الدخول الأولية: admin / ChangeMe123!

## النسخ والاستعادة
- إنشاء النسخة يحفظ قاعدة البيانات وجميع المرفقات.
- تظهر النسخ السابقة ضمن تبويب التقارير، وبجانب كل نسخة زر «استعادة».
- الاستعادة متاحة للأدمن فقط وتتطلب تأكيداً صريحاً بكتابة كلمة «استعادة».
- ينشئ النظام نسخة أمان تلقائية قبل استبدال البيانات.
- بعد النجاح يتم تسجيل الخروج، ثم يمكن الدخول ببيانات الحساب الموجودة في النسخة المستعادة.

## ملاحظات
- استخدم بيانات تجريبية أولاً وغيّر كلمة المرور الافتراضية.
- احتفظ بنسخة خارجية من مجلد backups على وسيط آمن.
- تكامل EEG مؤجل للمرحلة القادمة.
